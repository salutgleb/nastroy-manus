# «Настрой»: всё для сайта в Manus

Учебный проект команды 234-6, ВШБ ВШЭ, курс «Современные инструменты маркетинга и ИИ», семинар 6, 2026.

Страница для команды: архетип и название, голос бренда, цвета и шрифты, тексты первого экрана, упаковка и кадры товара, семантическое ядро из Вордстата, структура заголовков и бриф для Manus. Файлы для скачивания лежат в папке files. Страница закрыта от поисковиков.

Сам сайт: https://salutgleb.github.io/nastroy-site/
